# یەکسا · ئەپی سەرنشین (Flutter) · قۆناغی ١

هەمان Firebase ی وەشانی وێب بەکاردێنێت (`taxiakam-6d28f`). هیچ شتێک لە Firebase ناگۆڕێت و `firestore.rules` پێویستی بە Publish نییە.

## ئەوەی لەم قۆناغەدایە

- ناساندنی سەرەتا (سێ پەڕە)
- چوونەژوورەوە بە ژمارەی مۆبایل و وشەی نهێنی (هەمان هەژمارەکانی وێب)
- دروستکردنی ئەکاونت: ناو، ژمارە، وشەی نهێنی، ڕەگەز، شار، کۆدی بانگهێشت (هاوڕێ یان هاوبەش)
- شریتی خوارەوە بە پێنج بەش
- پرۆفایل: هەمان لیست، مەرج و ڕێساکان، کۆدی قوتابخانە/کۆمپانیا، چوونەدەرەوە
- ڕێکخستنەکان: ڕووکار (ڕووناک/تاریک/خۆکار)، قەبارەی نووسین، ژمارەکان (١٢٣ / 123)، گۆڕینی وشەی نهێنی
- ئەو بەشانەی ماون پەڕەی «لە قۆناغی داهاتوودا» پیشان دەدەن

## دانان (یەک جار)

1. لە تێرمیناڵی VS Code، لەناو فۆڵدەری **Documents**:
   ```
   flutter create --org com --project-name yeksa --platforms android,ios,web yeksa
   ```
   (ناسنامەی ئەپەکە دەبێتە `com.yeksa`؛ ئەپی شۆفێر دواتر `com.yeksa.driver` دەبێت)
2. ئەم ZIP ـە بکەرەوە و ئەمانە بخەرە ناو فۆڵدەری `yeksa` (لە جێگەی کۆنەکان):
   `lib`، `assets`، `test`، `pubspec.yaml`، `README.md`
3. لە VS Code: **File ← Open Folder ← yeksa**، پاشان **Trust**.
4. لە تێرمیناڵ:
   ```
   flutter pub get
   ```
5. لە خوارەوەی لای ڕاست **Chrome** هەڵبژێرە و **F5** لێبدە.

## تاقیکردنەوە لەسەر ئایفۆن (هەمان وایفای)

```
flutter run -d web-server --release --web-hostname 0.0.0.0 --web-port 8080
```
لە Safari: `http://192.168.0.103:8080` (IP ی کۆمپیوتەرەکەت).
بۆ چوونەژوورەوە، IP ـەکە دەبێت لە Firebase ← Authentication ← Settings ← Authorized domains هەبێت (بۆ وەشانی وێب پێشتر زیادت کردووە).

## ئەندرۆید و ئایفۆن (دواتر)

`lib/firebase_options.dart` ئێستا تەنها وەشانی وێبی تێدایە. کاتێک ویستت لەسەر ئەندرۆید یان ئایفۆن ڕایبکەیت، فەرمانی `flutterfire configure` لێبدە (پڕۆژەی `taxiakam-6d28f` هەڵبژێرە) و ئەم فایلە نوێ دەبێتەوە.

## پێکهاتە

```
lib/
├── main.dart              دەستپێکردن
├── app.dart               ڕووکار، ڕاست بۆ چەپ، دەروازەی چوونەژوورەوە
├── firebase_options.dart  ڕێکخستنی Firebase
├── core/
│   ├── cloud.dart         پەیوەندی بە Firestore (هاوتای ستۆری core.js)
│   ├── auth.dart          چوونەژوورەوە، تۆمارکردن، بانگهێشت
│   ├── defaults.dart      یاسا و شارە بنەڕەتییەکان
│   ├── format.dart        ژمارە، کات، پارە
│   └── settings.dart      ڕێکخستنەکانی ئەم ئامێرە
├── ui/                    ڕەنگ، ئایکۆن، لۆگۆ، دوگمە، کارت، شریتی خوارەوە
└── screens/               پەڕەکان
```

ڕەنگەکان لە `lib/ui/theme.dart`ـن (هەمان ژمارەکانی `core.css`). ئایکۆنەکان هەمان SVG ی وەشانی وێبن.
